The クールソウルゲーム Online Beta 1.0.1
========================================

■ 今回の追加
- 3～8人オンラインルーム
- 6文字の参加コード
- ホストがゲーム開始
- 各プレイヤーの手札を本人にだけ送信
- ターン / 山札 / 捨て札 / ポイント / 脱落 / ログをリアルタイム同期
- 割り込みカードの選択を該当プレイヤー本人の端末に表示
- TRAP / UIトラップを対象プレイヤー本人の画面に表示
- チャット同期 + 会話系カード判定
- 切断後の自動再接続用セッション保存
- 92種類 × 各3枚 = 山札276枚

■ Windowsで同じWi-Fi内から遊ぶ
1. ZIPを解凍する
2. Node.js 18以上をインストールする
3. start_windows.bat をダブルクリック（新ランチャーは別ウィンドウを開き、エラーでも閉じません）
4. 黒い画面に表示されたURLをホストが開く
5. 「ルームを作る」を選ぶ
6. 参加コードを友達に送る
7. 友達は同じWi-Fiから、黒い画面に出た「LANの参加URL」を開く
8. 「ルームに参加」で参加コードを入力する
9. 3～8人揃ったらホストがゲーム開始

■ Mac / Linux
ターミナルでこのフォルダを開き、次を実行:
  ./start_mac_linux.sh
または
  node server.js

■ インターネット越しに遊ぶ
このプロジェクトは普通のNode.js HTTPサーバーなので、Node.jsを動かせるホスティングへ配置できます。
起動コマンド:
  node server.js
ポート:
  環境変数 PORT を使用（未指定なら3000）

Dockerfileも同梱しています。
Render / Railway / Fly.io / VPS等へ配置すれば、参加者は同じURLへアクセスして遊べます。

注意:
- 現在のルーム情報はサーバーのメモリに保存しています。サーバー再起動でルームは消えます。
- 無料ホスティングのスリープ/再起動でもルームが消える場合があります。
- Online Betaなので、切断・同時操作・複雑な割り込みは今後さらに耐久テスト予定です。
- ブラウザのタブを閉じても、同じブラウザならセッション情報から再接続を試みます。

■ ゲーム仕様
- 3～8人
- 初期手札5枚
- 通常 / 継続 / 特殊 / TRAPは自分のターンに1枚
- 割込カードは条件成立時に別枠
- ラウンド勝利で1ポイント
- 3ポイント先取でゲーム勝利
- 92種類すべて3枚ずつ、計276枚


■ 起動できない場合
- diagnose_windows.bat をダブルクリックしてください。
- 黒い画面が閉じずに診断結果を表示します。
- Node.js が見つからない場合は Node.js 18以上をインストールしてください。
- ZIPの中から直接BATを実行せず、必ずフォルダへ解凍してから起動してください。
